# Security

This is a personal fork that is not published to either extension store. Only the latest
[GitHub release](https://github.com/denchen/instagram-download-browser-extension/releases/latest)
is supported, and there is no release cadence.

To report a vulnerability, use
[private vulnerability reporting](https://github.com/denchen/instagram-download-browser-extension/security/advisories/new)
rather than a public issue.
